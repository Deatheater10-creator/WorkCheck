Who does what?

Python runs the instructions. Streamlit builds the browser interface. SymPy manipulates maths expressions exactly. WorkCheck's own rules decide whether working is unfinished, complete, wrong or unclear. CSS changes the appearance; JSON stores the local draft. No external AI service is used.

Three-stop reference route

Reference walkthrough of an automatically checked example, not a claim that you completed a new hands-on exercise. In Differentiation, try f(x) = x^2 sin(x) with f'(x) = 2x cos(x). The first line is wrong because it multiplies the two derivatives. The product rule needs two terms added together.

Stop 1 · The click

Open workcheck/ui.py. Find main, then Check working. The button captures the current input and calls run_check. Sentence forms first require confirmation.

Stop 2 · The decision

Open workcheck/differentiation.py. Find check_differentiation. It checks each numbered line and stops dependent checks after a mistake or uncertainty. verification.py · verify supplies the exact mathematical evidence.

Stop 3 · The learning

Return to workcheck/ui.py. Find show_result and show_learning. They render checked data. practice.py and presentation.py prepare and verify the teaching before it reaches these functions.

How partial fractions uses the same route

check_partial_fractions replaces the differentiation checker. Its _setup records the A/B fractions; _coefficient_equation checks later equations against that context. Thus a valid A+B equation is an intermediate step, and swapped letters or a valid alternative method can still be accepted.

What the four outcomes mean
  • Valid intermediate step: correct so far, still unfinished.
  • Correct final answer: a verified complete derivative or decomposition.
  • First mistake: the first supported step shown to be incorrect.
  • Needs clarification: unsupported notation, missing context or proof the checker cannot establish. This is not a guessed error.

To change this, start here

  • Concept wording: explanations.py, NOTES.
  • Worked-step wording and equation formatting: presentation.py, _derivative_rule, coefficient_solution and school_latex.
  • Progressive reveals: ui.py · show_worked_steps. This controls visibility, not correctness.
  • Motion and colours: styles.css. Reduced-motion preferences disable effects.
  • Ordinary notation: parser.py · _normalize_multiplication. Preserve name recognition, bounds and ambiguity checks.
  • Saved work: storage.py · DraftStore. Do not store computed feedback as a draft.

An optional safe edit is one explanatory sentence in NOTES, leaving the formula unchanged. No edit is required or claimed here. A retained change should be checked and committed.

A practice to reuse

Give the agent a concrete example and expected result. The ordinary-notation regression in tests/test_ordinary_notation.py checks forms such as 3x^2 sin(2x); tests/test_differentiation.py checks the product-rule mistake and unfinished working. The PRD specifies the outcomes. On a future project, connect the requested behaviour to a test and then inspect the actual screen.

The startup regression in tests/test_worker.py checks another useful boundary: a maths worker importing app.py must not import the interface. The launch guard avoids that extra work without extending calculation deadlines.

What this snapshot does not promise

Typed first real differentiation and restricted partial fractions are the tested scope. Full curriculum coverage, handwriting recognition, complex logarithm branches, point evaluation and automatic practice grading are not implemented. Photo input retains the approved typed-only fallback. See coverage.md and the readiness report for boundaries and evidence.

Run again

In PowerShell from the WorkCheck folder, after the one-time setup:

.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false

Open http://127.0.0.1:8501. Keep the terminal open; Ctrl+C stops it. Full setup and troubleshooting: README.md. Reopen this guide by opening devpost/app-map.html in your browser. No server or internet is needed to read the map.
